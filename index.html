Project Overview

ราคาทองคำได้รับอิทธิพลจากหลายตลาด โปรเจกต์นี้จึงออกแบบระบบสำหรับรวบรวมข้อมูลย้อนหลัง เตรียมข้อมูล ทดสอบโมเดล และนำเสนอผลการวิเคราะห์ในที่เดียว

◉

Multi-source Data

Gold Futures, Silver Futures, DXY, USD/THB, S&P 500, US10Y Yield, VIX และ WTI

⟲

Automated Pipeline

ใช้ Apache Airflow จัดการขั้นตอน Ingestion, Data Processing และ ML Workflow

⌁

ML Evaluation

ทดลอง Ridge, Random Forest และ Histogram Gradient Boosting พร้อมการประเมินตามลำดับเวลา

Dashboard Experience

ตัวอย่างแนวทางการออกแบบหน้ากราฟด้วยธีมมืดและสีเขียว–แดงแบบแพลตฟอร์มการเงิน (กราฟด้านล่างเป็นภาพสาธิต UI ไม่ใช่ข้อมูลราคาจริง)
